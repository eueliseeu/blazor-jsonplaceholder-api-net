# BlazorUsersJsonPlaceHolderApi

Aplicação Blazor WebAssembly em .NET 10 que consome a API pública JSONPlaceholder para obter usuários.

Este projeto foi desenvolvido como uma atividade acadêmica para fins de estudo.

## Autor

Eliseu Pereira da Silva - RA 124220479

Endpoint utilizado: https://jsonplaceholder.typicode.com/users

## Requisito

- .NET SDK 10.0 ou superior

## Executar

Na pasta do projeto, rode:

```bash
dotnet run
```

Abra no navegador a URL exibida no terminal.
